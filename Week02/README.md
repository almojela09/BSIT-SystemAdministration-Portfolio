# BSIT System Administration Portfolio

## Week 02 – Enterprise Infrastructure Plan

### Project Overview

This project contains the complete IT Infrastructure Plan for **ABC Startup Solutions**, a fictional software development startup with **20 employees**. The project demonstrates enterprise infrastructure planning, hardware and software inventory management, network design, security planning, backup strategy development, and professional technical documentation.

---

## Learning Objectives
- Analyze organizational IT requirements
- Prepare enterprise hardware and software inventories
- Design a professional network topology
- Create technical documentation using Markdown
- Present infrastructure recommendations professionally

---

## Company Scenario
APEX Solutions is a newly established software development company with four departments:
| Department | Employees |
|------------|-----------|
| IT | 5 |
| HR | 4 |
| Finance | 5 |
| Sales | 6 | | **Total** | **20** |

The company initially has **no computers, servers, network, or security infrastructure**, requiring a complete infrastructure design from scratch.
