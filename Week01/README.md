# Reflection

This activity made me realize that system administration involves more than simply knowing how to use a computer. Before starting the actual tasks, there is already a lot of preparation involved in making sure that the working environment is ready. Setting up Git, GitHub Desktop, Visual Studio Code, Oracle VirtualBox, Ubuntu Desktop, and Windows 11 Enterprise showed me how different tools can work together to support different technical tasks.

What I found most interesting was using VirtualBox to create a separate environment for operating systems. It gave me a better idea of how virtualization can be useful when testing configurations or learning a new system. Instead of worrying about damaging my main computer, I can use a virtual machine to experiment, make mistakes, and learn from them. I also realized that tools like Git are not only for programmers because keeping track of changes and maintaining organized files can also be useful when managing system-related projects.

Another thing I learned is that technical work requires patience and attention to detail. Some parts of the setup may seem simple, but a small mistake in configuration can affect the entire process. This taught me to be more careful when following instructions and to understand what I am doing instead of simply completing each step. Overall, the activity gave me a better foundation for the upcoming laboratory exercises. I know I still have a lot to learn, but becoming familiar with these tools gives me more confidence to explore operating systems, virtualization, and system administration in the activities ahead.
